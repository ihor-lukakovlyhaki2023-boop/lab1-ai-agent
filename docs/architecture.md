# Архітектура AI-агента
## Компоненти системи
- **Agent Manifest**: визначає межі відповідальності, правила безпеки та цілі агента.
- **Skills**: модульні інструкції для окремих типів завдань (ініціалізація коду, збірка, CI).
- **Commands**: окремі операції, доступні для виконання користувачем.
- **Orchestrator (init)**: покроковий координатор пайплайну з перевіркою результатів кожного етапу.

## Потік виконання
init -> git-init -> create-project -> create-build -> create-actions -> check.
